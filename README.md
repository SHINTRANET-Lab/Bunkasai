# 得点板システム
2025/11/1の文化祭で実際に使用されたキックボーリング向けの得点板ソフトウェアです  
GPT-5 miniによって書かれ、信濃眞伊によって修正されました。  
本来の役目は果されたため、公開します。  
このシステムは既にサポートを終了しています。
## How to use
node.js v24.11.0を使用します。  
ソースファイルの階層に移動します  
`node server.js`でlocalhost:3000にサーバが立ちます。  
使い方は[得点板システムマニュアル公開版](https://shinanomai.xyz/file/page/20251101_M.html)で公開しています。
