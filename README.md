# BUnkasai - 得点板 (キックボーリング)

ローカルで動くシンプルな得点板（表示）と管理画面（admin.html）です。
サーバーは Node.js の組み込みモジュールのみを使い、SSE (Server-Sent Events) で表示側に更新を配信します。

使い方（Windows PowerShell）:

1. Node.js (14+) が必要です。
2. リポジトリのルートでサーバーを起動します:

```powershell
npm start
```

3. ブラウザで表示ページ:
 - ボード1: http://localhost:3000/?board=1
 - ボード2: http://localhost:3000/?board=2

4. 管理画面:
 - http://localhost:3000/admin.html

管理画面から複数ボードをカンマ区切りで指定して同時操作できます。空欄にすると全ボードに対するブロードキャストになります。

簡単な実装のため再起動や永続化はありません。改良案:

- 永続ストレージ（現在の得点/タイマーを保存）
- WebSocket 対応（双方向）
- 画面ごとのレイアウト調整や大画面表示モード
